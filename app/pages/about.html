About This Template

This is a modern, clean eCommerce template built with plain HTML, CSS, and JavaScript. It includes category pages, a quantity-based cart, responsive navigation, and demo checkout behavior.

What’s included

  • Category pages powered by a single JavaScript renderer
  • Products loaded from /data/items.json
  • Quantity cart stored in localStorage
  • Mobile-friendly layout and navigation
  • MIT License credit footer
